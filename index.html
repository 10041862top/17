⚠️ 為什麼不能在網頁直接填表？
基於網頁瀏覽器的安全沙盒與跨域（CORS）限制，本網頁無法直接操控政府入口網站。因此，我們提供了一支強大的 Python Playwright 自動化外掛腳本，讓您的電腦可以直接接管瀏覽器，將 AI 寫好的文件自動貼上政府表單！

如何執行？ (SOP)

  1. 請將上面下載的 ai_generated_document.txt 與 autofill.py 放在同一個資料夾。
  2. 打開終端機 (Terminal) 或命令提示字元 (CMD)。
  3. 確保您的電腦已安裝 Python，並輸入以下指令安裝套件：
    pip install playwright && playwright install chromium
  4. 執行自動填表腳本：
    python autofill.py
  5. 程式會幫您打開瀏覽器並進入入口網站。請您在畫面上**手動插入工商憑證登入**。登入完成後，在終端機按下 Enter，程式就會自動接管並一格一格幫您填滿表單！
