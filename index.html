核心功能特色

結合最新 AI Agent 技術，讓申請流程自動化

自動調研與分析

自動抓取競賽簡章（HTML/PDF），瞬間建立競賽資訊表與競品比較矩陣，掌握致勝關鍵。

智慧文件撰寫

根據競賽與補助要求，自動產出作品說明書、簡報腳本、及加分佐證文件清單，大幅節省構思時間。

自動化填表

支援 Computer Use、Playwright 腳本或半自動輔助，快速將資料帶入繁瑣的政府平台表單中。

15+ 平台知識庫

內建台灣主要補助、競賽、標案平台資料，結構化資料自動帶入流程，免去四處尋找資訊的困擾。

每週自動更新

透過 GitHub Action 定期爬取各平台，同步最新的補助金額、截止日與受理狀態。

主動推播機會

每週一自動建立 GitHub Issue 發送週報，訂閱即可透過 Email 掌握最新補助與標案關鍵字。
